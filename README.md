# 字母探险队

面向 5 岁儿童的英文字母学习网站，主要适配 Mac 笔记本。纯前端运行，无账号、数据库或服务端依赖。

## 在另一台 Mac 上双击启动

1. 将整个项目文件夹拷贝到另一台 Mac（例如“文稿”目录），不要只拷贝启动脚本。可以不拷贝 `node_modules`、`.venv`、`.git`、`.artifacts`、`dist`，这些不是启动必需文件。
2. 双击项目根目录的 **`启动字母探险队.command`**。
3. 如果尚未安装 Node.js，脚本会打开官网，请安装 **LTS 版本**，然后再次双击。
4. 首次启动自动安装依赖，需要联网；之后自动启动并打开浏览器。

学习期间保留终端窗口。结束时在终端按 **Control + C**；下次再次双击即可。重复双击会打开已经运行的网站，不会重复启动服务。

默认固定地址为 `http://127.0.0.1:5173/`，保持同一浏览器和地址可继续本机学习进度。原电脑的浏览器进度不会随项目文件一起迁移。

若 macOS 阻止直接双击，可以先右键脚本选择“打开”。如果拷贝后提示没有执行权限，在终端输入 `chmod +x `（末尾留一个空格），将该脚本拖入终端，再按回车。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地网址（默认 http://127.0.0.1:5173）。

```sh
npm run build
npm run preview
```

`dist/` 是静态部署产物，可部署到静态网站托管服务。页面使用 hash 路由，不需要服务端路由重写。当前版本在本地开发，未发布到公网。

## 四个页面

- **探险首页**：森林、恐龙、太空和汽车主题；开始 / 恢复探险；贴纸册。
- **认识字母**：26 个大小写字母、字母名称发音、四线三格、小写键位单独练习。
- **闯关练习**：可跳过的 12 题小写摸底；9 轮按 a–z 顺序的课程；认字母、大小写配对、找按键、看图输入单词。最后一轮学习 y、z。
- **家长中心**：练习记录、复习提示、语音开关 / 音量、字母选择及 A4 描红纸预览 / 打印。

摸底只记录已回答的字母，未测字母不判为不会。已认识的字母减少配对练习；后续课程会带上一个已练过且容易混淆的字母复习。所有图片都是随项目附带的 SVG 插画。

## 第一次陪孩子使用

1. 将 Mac 输入法切换为英文 ABC。
2. 在家长中心点击“试听中文和英文”，确认浏览器能播放系统的中英文语音。
3. 从首页点击“开始今天的探险”；孩子之后可以跟着中文引导完成一轮。
4. 打印时选 A4、实际大小，关闭浏览器页眉页脚；也可以选择“存储为 PDF”。

浏览器语音使用 `speechSynthesis`，声音质量和可用语言由设备及浏览器决定。无语音支持时，家长中心显示提示。键盘练习面向真实物理键盘；手机适配用于浏览、家长设置，不提供触屏打字模式。

进度保存于当前浏览器的 `localStorage`，刷新后可继续；清除网站数据、换浏览器或换设备后不自动同步。可以选择关闭声音。不设倒计时、扣分、排行榜或签到惩罚。

## 字体与打印

英文字母使用 SIL Andika（OFL），随构建产物分发，不依赖在线字体加载。许可证在 `public/fonts/Andika-OFL.txt`。

四线三格使用同一字体导出的 SVG 轮廓，依据字体 x-height 对齐中格与基线；a、g 为单层字形。轮廓文件 `src/glyphs.json` 已入库，正常开发无需 Python。需更新字体轮廓时：

```sh
python3 -m venv .venv
.venv/bin/pip install -r tests/requirements.txt
.venv/bin/python scripts/generate_glyphs.py
```

## 验证

```sh
npm test
npm run build
```

浏览器端到端测试（另一个终端先运行 `npm run dev`）：

```sh
python3 -m venv .venv
.venv/bin/pip install -r tests/requirements.txt
.venv/bin/playwright install chromium
.venv/bin/python tests/browser.py
.venv/bin/python tests/last-lesson.py
```

覆盖摸底、完整关卡、错误 / 长按 / 大写输入、刷新恢复、单词完成时中断、单字练习不覆盖课程、声音开关、A4 分页与响应式布局。截图和测试 PDF 输出在忽略的 `.artifacts/` 中。语音测试验证调用与语言选择，不替代真人试听。

## 文件结构

- `src/main.js`：页面、事件和学习流程。
- `src/state.js`：本地保存、恢复和数据校验。
- `src/data.js`：课程、词库与主题。
- `src/art.js`：插画和图标。
- `src/audio.js`：中英文语音与提示音。
- `src/style.css`：页面、响应式布局与打印样式。
- `docs/design.md`：视觉设计方向。
- `.agents/skills/`：项目开发技能。
