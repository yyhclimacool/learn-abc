# 字母探险队：首版设计

采用儿童探险绘本方向，以小狐狸和可切换世界的插画为视觉中心。教学页降低装饰密度，保留大目标、明确操作和随时可用的声音提示。

- 天空底色 #F4F8FB；文字 #293F48；森林绿 #447C59；草地 #E8F2DF；奖励黄 #EDBC55；辅助蓝 #E9F2F8。
- 中文采用系统字体；英文字母采用随包分发的 SIL Andika。四线三格直接使用字体轮廓，按实际 x-height 对齐中线与基线，保持打印与屏幕一致。
- 首页：导航 / 左侧开始探险＋右侧世界插画 / 四个主题 / 本轮目标＋贴纸册。
- 字母页：字母选择网格＋当前字母学习卡。
- 关卡页：四步进度＋单个当前任务＋帮助与声音＋键盘提示。
- 家长页：练习概览＋声音设置＋打印选择。

设计检查：主题选择服务于孩子自主决定；绘本插画集中在首页，关卡避免同屏动画和奖励抢注意力。不以速度、积分排名或扣分驱动练习。所有动作可通过键盘操作，尊重减少动画偏好。
